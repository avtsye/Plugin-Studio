# Otzaria Plugin Studio

סביבת פיתוח לתוספי Otzaria שרצה כתוסף בתוך Otzaria.

## יעד גרסה 0.1
- מנהל פרויקטים מקומי
- סייר קבצים
- עורך HTML/CSS/JavaScript/JSON
- יצירה, שינוי שם ומחיקת קבצים
- שמירה אוטומטית ב-localStorage
- תבנית תוסף חדשה עם manifest תקין
- קטלוג SDK והרשאות המבוסס על המפרט הרשמי של Otzaria

> הפרויקט משתמש רק ביכולות ש-Plugin API הרשמי חושף ואינו דורש שינוי בקוד הליבה של Otzaria.
